编译流程、字节码、帧与命名空间、引用计数 GC、GIL、导入系统、性能剖析。阶段划分不是按知识点罗列，而是按「学完能交付什么」倒推：前一阶段的输出正好是这一阶段的前置，跳过某一段往往会在后面某讲突然卡住，届时再回来补齐比按顺序学更费时。
