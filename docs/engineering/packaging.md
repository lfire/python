# 第 080 讲 · 打包与发布：pyproject、wheel 与 PyPI

> wheel 是已经组织好的安装产物，sdist 是源码；只上传 sdist 会让用户在安装时还要跑一遍构建，失败率明显更高。本讲的目标是「把项目做成别人一行命令能装的东西」。先建立直觉，再用可运行代码把规则固定下来，最后放进工程场景里看边界与代价；全程建议边读边改参数、边猜输出。

### 用命令行复现

本机不用起服务，一条命令就能把本讲的关键行为再验证一次：

```bash

```

把命令里的输入换成你自己的数据，观察输出是否仍符合 **构建后端与 PEP 517** 的规则；若结果不一致，先核对 Python 版本与依赖版本，再回到主示例逐行定位差异。这条命令也可以直接加进 CI，作为本讲结论的回归检查。
