# 阶段导览 · 工程化

> 把脚本变成可维护、可测试、可发布、可诊断的工程。本阶段共 11 讲，覆盖 项目结构、依赖与锁、规范与类型、测试与 Mock、日志配置、打包与 CI/CD。建议按顺序推进：每讲都先建立直觉、再跑通示例、最后看工程边界，讲与讲之间的依赖关系在下面的地图里一目了然。

## 这个阶段解决什么问题

项目结构、依赖与锁、规范与类型、测试与 Mock、日志配置、打包与 CI/CD。阶段划分不是按知识点罗列，而是按「学完能交付什么」倒推：前一阶段的输出正好是这一阶段的前置，跳过某一段往往会在后面某讲突然卡住，届时再回来补齐比按顺序学更费时。
