# 阶段导览 · 工程实战

> 把前十一个阶段的知识在十二类真实场景中反复用熟。本阶段共 11 讲，覆盖 CLI、办公自动化、Web、爬虫、数据、AI、存储、分布式与贯穿式 KV 演进线。建议按顺序推进：每讲都先建立直觉、再跑通示例、最后看工程边界，讲与讲之间的依赖关系在下面的地图里一目了然。

## 这个阶段解决什么问题

CLI、办公自动化、Web、爬虫、数据、AI、存储、分布式与贯穿式 KV 演进线。阶段划分不是按知识点罗列，而是按「学完能交付什么」倒推：前一阶段的输出正好是这一阶段的前置，跳过某一段往往会在后面某讲突然卡住，届时再回来补齐比按顺序学更费时。
