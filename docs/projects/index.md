# 阶段导览 · 工程实战

前面十二个阶段的知识，最终要在真实场景里反复用熟才算自己的。这个阶段不再引入新语法，而是把已经学过的东西组合成能交付的东西。

前半段是几类独立实战：待办清单 CLI、文件检索与日志、邮件与 PDF/Excel/Word 自动化、浏览器表单自动化、短链与图片服务、日志 ETL、并发爬虫。后半段是一条贯穿线——KV 存储从内存版与接口抽象开始，加上网络协议帧，再补 WAL 与崩溃恢复，最后做分片、副本与网关收束。递进非常明确：单文件工具 → 有状态服务 → 可恢复存储 → 分布式系统，每一次只替换一个变量，所以能清楚看到新增的复杂度来自哪里。

建议 KV 四讲按顺序做，并且每一讲都让上一讲的同一组契约测试继续通过；这是检验抽象是否站得住的最直接办法。到这里你需要的已经不是提示，而是一份自己的检查表：数据量上来后是否还成立、并发进入后谁拥有状态、失败之后谁负责收尾。

## 这个阶段解决什么问题

CLI、办公自动化、Web、爬虫、数据、AI、存储、分布式与贯穿式 KV 演进线。阶段划分不是按知识点罗列，而是按「学完能交付什么」倒推：前一阶段的输出正好是这一阶段的前置，跳过某一段往往会在后面某讲突然卡住，届时再回来补齐比按顺序学更费时。
