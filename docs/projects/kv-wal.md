### 2.1 主示例

**追加写与 fsync**。从实现角度看，这一层的行为最终会落到对象协议、字节码或运行时状态上。理解底层并不意味着每次都要写底层代码，而是当现象与直觉不符时，你知道该用 dis、inspect、tracemalloc 还是 cProfile 去验证，从而把猜测变成证据。

```python
import asyncio, json

async def handle(reader, writer):
    raw = await reader.read(1024)
    cmd = json.loads(raw.decode())
    writer.write(json.dumps({"ok": True, "cmd": cmd}).encode())
    await writer.drain()
    writer.close()

print(callable(handle))
```
