### 2.1 主示例

**先算法后实现**。先把这个概念放进可验证的场景：写一段最小代码，观察它的输出，再回头读规则。很多误解来自只记结论、没有亲手跑过边界情况；本讲要求把每一步的结论都用一段可运行代码固定下来，而不是停在「大概是这样」。

```python
from functools import lru_cache
@lru_cache(None)
def fib(n): return n if n < 2 else fib(n-1)+fib(n-2)
print(fib(35))
```
