# 阶段导览 · 资深进阶

到这里，你应该已经能从一个异常现象推到大致的成因，也知道该用什么工具验证。资深阶段要补的是最后一环：读懂实现本身，并把判断从「这段代码」抬到「这个系统该怎么演进」。

前六讲沉到 CPython 内部——对象与求值循环、pymalloc 与 GC、导入系统、asyncio 事件循环、GIL 与自由线程化、以及从剖析到 C 扩展的十倍优化；后两讲抬回工程视角，讨论领域分层、架构演进与技术决策的写法。递进是「会用 → 会读实现 → 会做带代价的技术决策」。第一一八讲的 PEP 659/703 会提醒你：很多性能与 GIL 结论都绑定解释器版本与构建方式，读旧文章时务必先确认前提。

这一阶段不追求背源码文件名，更看重能否把语言现象映射到具体实现路径，并在信息不全时写出「问题—约束—备选—代价—验证—回退」这样一份可被反驳的提案。
