### 2.1 主示例

**函数作为值**。从实现角度看，这一层的行为最终会落到对象协议、字节码或运行时状态上。理解底层并不意味着每次都要写底层代码，而是当现象与直觉不符时，你知道该用 dis、inspect、tracemalloc 还是 cProfile 去验证，从而把猜测变成证据。

```python
def make_adder(n):
    def add(x):
        return x + n
    return add

add3 = make_adder(3)
print(add3(4))
print(add3.__closure__[0].cell_contents)
```
