### 2.1 主示例

**三层函数结构**。建议把它和相邻知识点连成一条线：输入是什么、状态存在哪里、失败时谁负责收尾。这三问能覆盖绝大多数线上问题，也是后续阶段反复使用的分析框架；能回答这三问，才算真正掌握而不是记住了 API 名字。

```python
from functools import lru_cache

@lru_cache(maxsize=128)
def fib(n):
    return n if n < 2 else fib(n-1) + fib(n-2)

print(fib(30), fib.cache_info())
```

### 2.2 对照写法

```python
from functools import singledispatch

@singledispatch
def show(x): return "other"
@show.register
def _(x: int): return f"int {x}"
print(show(1), show("a"))
```
