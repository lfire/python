## 2. 语法与规则：把行为跑出来

### 2.1 主示例

**装饰器即函数替换**。工程里最容易出问题的不是不会用，而是用在错误的边界上：数据规模变大、并发进入、依赖升级、跨平台部署之后，原本成立的假设会逐个失效。因此本讲同时给出适用条件、失效信号和一条可回退的路径。

```python
from functools import wraps
import time

def timed(fn):
    @wraps(fn)
    def wrapper(*args, **kwargs):
        t0 = time.perf_counter()
        try:
            return fn(*args, **kwargs)
        finally:
            print(f"{fn.__name__}: {time.perf_counter()-t0:.4f}s")
    return wrapper

@timed
def slow():
    return sum(range(10**6))

print(slow())
```

### 2.2 对照写法

```python
def repeat(n):
    def deco(fn):
        @wraps(fn)
        def wrapper(*a, **k):
            return [fn(*a, **k) for _ in range(n)]
        return wrapper
    return deco

@repeat(3)
def hello(): return "hi"
print(hello())
```
