# 阶段导览 · 函数与抽象

写着写着，同样的几行代码开始在不同地方重复出现。这一阶段解决的是「把变化的部分抽出来」：先抽成函数，再抽成可组合的策略，最后抽成能被别人导入的模块。

我们把参数形态、返回值与 None、作用域与闭包、高阶函数、装饰器、偏函数、模块与包、类型注解依次排开，最后用一个缓存装饰器库与插件注册表收束。顺序按抽象程度递增：先是「一次调用怎么传值」，再到「函数本身能不能当值传来传去」，最后是「一组函数怎么组织成一个可发布的模块」。

有两处值得放慢：第三十讲的闭包延迟绑定，和第三十二讲的装饰器求值时机——它们都是「代码看着对、结果却不对」的高发区。类型注解那一讲则说明一个容易被误解的边界：注解默认不强制运行时校验，真正的约束力来自静态检查器。学到这里，你已经可以开始写自己的小工具库了。
