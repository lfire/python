# 阶段导览 · 函数与抽象

> 用函数、装饰器、模块与类型注解搭出可复用的抽象。本阶段共 10 讲，覆盖 参数形态、作用域闭包、高阶函数、装饰器、模块包与类型系统。建议按顺序推进：每讲都先建立直觉、再跑通示例、最后看工程边界，讲与讲之间的依赖关系在下面的地图里一目了然。

## 这个阶段解决什么问题

参数形态、作用域闭包、高阶函数、装饰器、模块包与类型系统。阶段划分不是按知识点罗列，而是按「学完能交付什么」倒推：前一阶段的输出正好是这一阶段的前置，跳过某一段往往会在后面某讲突然卡住，届时再回来补齐比按顺序学更费时。
