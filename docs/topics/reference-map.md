# 参考课程对照与学习路线

这一篇不教新语法，它是全站的对照索引。最初规划时手边摆着 7 门慕课课程，从语法入门、核心技术到底层原理、机器学习、多领域实战都各有侧重；本站没有照着某一门课的顺序复刻，而是按「从零到资深、覆盖尽可能全的工程场景」重新划成 13 个阶段、132 讲。回头清点时发现，有些场景只在生态地图的场景清单里列过名字，正文没有对应的篇幅。下面把 7 门课的知识域逐项对到本站讲次，标出哪些已经覆盖、哪些由专题补遗接住、哪些属于跨岗位扩展只给索引，最后按学习目标给三条选读路线。

## 7 门参考课程与本站的重新定位

最初参考的 7 门课程诉求各异：C1、C2 打语法底子，C4 往 CPython 底层和并发里钻，C3、C5 铺开工程岗位与项目场景，C6 讲机器学习经典算法，C7 补环境工程与大模型应用。若照单全收，同一个「函数」会在三门课里重复出现，而正则、工程底座、报告导出这些卡手的环节反而没人负责。

本站因此重新定位：以 Python 语言的递进为经，以「从零到资深、覆盖尽可能全的工程场景」为纬。语言主线从对象模型、容器、函数、类走到字节码、GIL、并发与源码，工程主线从工具链、测试、服务端、数据与 AI 走到分布式、部署与架构，再用 11 讲实战把散落的知识点串成能跑的项目。凡属于另一门语言或另一个岗位的深度，本站只给索引，不占正文篇幅。

## 跨岗位扩展路线只给索引

C3 把前端、运维、数据库管理、测试、全栈和桌面 GUI 都收进了课程，这些方向各自能撑起独立岗位，展开任一条都会把教程从「Python 语言与工程场景」拖进另一套知识体系。本站只在正文和专题里保留 Python 调用这些能力的接口，方向本身给索引，不写成分步教程。

| 跨岗位方向 | 本站给到什么 | 只给索引的原因 |
| --- | --- | --- |
| 前端 HTML / CSS / JS | 83 讲框架选型点到模板与静态资源，web-frameworks 专题用到 jinja2 模板 | 属于另一条语言主线，展开语法会稀释 Python 工程场景 |
| Linux 运维 | 72 讲依赖管理、110 讲容器化提到部署环境 | 运维体系偏系统命令与服务编排，本站以 Python 调用系统能力为界 |
| MySQL DBA | 87 讲讲 ORM、连接池与事务，toolchain-foundation 专题补 SQL 基础查询 | 索引设计、备份、主从与调优是独立岗位深度，正文只保留应用侧用法 |
| 软件测试 | 75 / 76 讲单元测试与 Mock，testing-automation 专题补接口与 UI 自动化 | 用例管理、CI 门禁、性能压测自成体系，专题给最小可跑闭环 |
| Django 全栈 | 83 讲选型提到 Django，web-frameworks 专题用 Flask 走一遍分步开发 | 全栈还牵涉前端与部署，本站以「一个框架跑通」为限 |
| GUI 桌面 | office-advanced 专题给 Tkinter 最小 GUI 与多线程 | 桌面应用不是本站工程场景主线，点到能跑通即可 |

本站保持 Python 语言与工程场景主线，跨岗位方向只给索引。

## 按目标选三条路线

### 零基础顺序学

从第 1 讲开篇、第 2 讲环境与工具链、第 3 讲第一行 Python 起步，沿语言主线走到第 16 讲交互式命令行计算器收口；接着 17 到 48 讲把容器、函数、类与数据模型打扎实，第 48 讲的最小 ORM 是第一个综合件。之后按兴趣分流：工程化看 71 到 81 讲，数据看 93 到 96 讲。第 5 讲定顺序，第 121 讲的资深能力图谱定终点。

### 有经验按短板补

先拿大对照表自查：正则没系统学过补 `regex` 专题；环境、Git、SQL 不熟补 `toolchain-foundation` 专题并对齐第 72 讲；只会选型补 `web-frameworks` 专题，回看第 83、87 讲；测试只有单元测试底子补 `testing-automation` 专题，对照第 75、76 讲。数据与 AI 侧的短板落在 `dl-projects`（接第 103 讲）和 `rag-frameworks`（接第 104 讲）。

### 只查一个具体问题

带着问题来不必通读。算疫情或一线城市房价、做医院科室费用透视、导出可复核的报告，看 `data-projects` 专题，细节回第 94、95、96 讲；实现 CSV / SQL 查询工具，看第 127 讲加 `data-projects` 专题里的 `sqlite3` 最小实现；接大模型 API 或做 RAG，看第 104 讲加 `rag-frameworks` 专题。查完按结尾链接回目录即可。

| --- | --- | --- |
