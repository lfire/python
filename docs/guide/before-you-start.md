# 开始之前

先不用打开编辑器。很多人学一门新语言时最先遇到的困难，其实不是语法，而是不确定自己该从哪里切入、眼前这一节在整个体系里占什么位置、以及读到什么程度算「可以往下走了」。这一页就是用来把这些交待清楚的，读完再开始，会顺很多。

## 这是一套什么样的教程

它是一套从零基础一直走到资深的 Python 中文教程，共 13 个阶段、132 讲、50 个工程场景。阶段顺序不是按知识点罗列，而是按「学完能交付什么」倒推的：先能对，再能快；先单进程，再并发；先会写，再会发布；最后才谈架构与源码。前一阶段的输出，正好是下一阶段的前置。

每一讲都自成闭环，但章节结构并不统一——有的讲按概念展开，有的讲按一次故障排查推进，有的讲直接就是分步实现。这是刻意的：主题不同，切法本来就该不同。共同点是每讲开头都有一段引入，先说清这一讲为什么出现在这里、需要哪些前置、会按什么顺序展开，然后才进入内容。

<Callout type="tip" title="不必从头到尾一字不落" text="教程支持跳读。每讲顶部标了难度与前置，侧栏按阶段分组，练习与速查里还有能力自评，随时可以回到某个短板补齐。" />

## 写给谁，也说不写给谁

| 你现在的状态 | 建议的走法 | 可以先跳过 |
| --- | --- | --- |
| 完全没有编程基础 | 从「开始之前」→ 导学阶段 → 第 001 讲，按编号顺序走 | 无，前两个阶段建议完整读 |
| 会 C / Java / JS，想转 Python | 先读第 005 讲学习路线，再从对象模型与容器阶段切入 | 导学的环境安装、基础控制流 |
| 已经写过 Python 脚本 | 用速查表与能力自评找短板，直接跳到对应阶段 | 编程地基、容器前半段 |
| 只想解决手头一个具体问题 | 用全文搜索、常见坑或生态地图定位，再回看该讲完整示例 | 大部分前置讲次 |

需要的最低基础只有两样：能打开终端、照着敲几条命令；以及愿意亲手把示例代码改坏一次再改回来。数学、算法、操作系统知识会在用到的地方补，不要求预先掌握。

## 开始之前只需要准备什么

一台能联网的电脑、一个 Python 3.10 以上的解释器、一个顺手的编辑器就够了。虚拟环境、依赖锁、格式化与测试工具会在第 002 讲和第 004 讲带着装，不用提前折腾。想先确认环境，可以跑这一条：

```bash
python -c "import sys, platform; print(sys.version_info[:3], platform.python_implementation())"
```

站点本身是静态页面，不需要数据库、服务端或账号；进度只存在你自己的浏览器里。

## 这个站点怎么用

| 你会看到 | 怎么用 | 为什么这样设计 |
| --- | --- | --- |
| 逐行讲解 | 点左侧任意一行，右侧给出这行在做什么 | 把「大概看懂了」逼成「能逐行说清」 |
| 先猜输出 | 运行结果默认藏起来，先自己想，再点开 | 主动回忆比多读一遍有效得多 |
| 代码填空 / 随堂检测 | 提交后立刻给解析，不只判对错 | 答错时讲清错在哪，才是学习发生的地方 |
| 动手练习 | 带提示，参考解默认折叠 | 先自己挣扎一下，再看答案 |
| 概念图 / 分层蓝图 / 时序图 | 点击放大，滚轮或双指缩放，拖拽平移 | 抽象机制画出来更好懂 |
| 一页纸速记 | 每讲结尾把要点和易错点分开列 | 复习时不用重读全篇 |
| 标记学完 | 每讲顶部打卡，首页按阶段汇总 | 进度只存本地，可随时清空 |
| 全文搜索 / 深色模式 | 顶栏搜索框与外观切换 | 查资料和长时间阅读都方便 |
