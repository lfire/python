# 阶段导览 · 导学

> 先看见整张地图：Python 是什么、怎么跑起来、这套教程怎么学。本阶段共 5 讲，覆盖 语言定位、环境与工具链、第一行代码、执行模型与学习路线。建议按顺序推进：每讲都先建立直觉、再跑通示例、最后看工程边界，讲与讲之间的依赖关系在下面的地图里一目了然。

## 这个阶段解决什么问题

语言定位、环境与工具链、第一行代码、执行模型与学习路线。阶段划分不是按知识点罗列，而是按「学完能交付什么」倒推：前一阶段的输出正好是这一阶段的前置，跳过某一段往往会在后面某讲突然卡住，届时再回来补齐比按顺序学更费时。
