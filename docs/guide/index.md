# 阶段导览 · 导学

先别急着装环境，也别急着敲第一行代码。刚开始学一门语言时，最容易消耗掉耐心的不是语法有多难，而是不知道自己正站在哪里、接下来要往哪走。这个阶段就是用来把地图摊开的。

五讲从「Python 通常被用在什么地方」开始，接着才谈解释器、虚拟环境与编辑器，然后带你把一行源码走到字节码再走到输出，补齐日常会用到的命令，最后说明十三个阶段为什么按这个顺序排。顺序刻意放得很缓：先能回答「我在学什么」，再回答「怎么让它跑起来」，最后才回答「我该按什么节奏读下去」。

读完之后，你应该能判断自己适合从头顺序学、按短板跳读，还是只查某个具体主题。已经有其它语言经验的人可以快一点，但仍建议看一眼第五讲的学习路线——后面很多看似奇怪的安排，依据都在那里。这里不需要任何编程基础，能打开终端、照着敲几条命令就够了。

## 这个阶段解决什么问题

语言定位、环境与工具链、第一行代码、执行模型与学习路线。阶段划分不是按知识点罗列，而是按「学完能交付什么」倒推：前一阶段的输出正好是这一阶段的前置，跳过某一段往往会在后面某讲突然卡住，届时再回来补齐比按顺序学更费时。
