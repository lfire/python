### 2.1 主示例

**串行基线**。这里的关键词是「什么时候」和「代价是什么」。Python 的机制大多不是非黑即白的开关，而是在可读性、性能与灵活性之间做的取舍。把取舍写清楚，遇到新版本或新框架时才能自己推导，而不是重新背一遍结论。

```python
import asyncio

async def fetch(i):
    await asyncio.sleep(0.01)
    return i * 2

async def main():
    return await asyncio.gather(*(fetch(i) for i in range(5)))

print(asyncio.run(main()))
```

### 2.2 对照写法

```python
import asyncio

```
