### 2.1 主示例

**并发与并行的区别**。这里的关键词是「什么时候」和「代价是什么」。Python 的机制大多不是非黑即白的开关，而是在可读性、性能与灵活性之间做的取舍。把取舍写清楚，遇到新版本或新框架时才能自己推导，而不是重新背一遍结论。

```python
from concurrent.futures import ThreadPoolExecutor, as_completed

def fetch(i):
    return i * i

with ThreadPoolExecutor(max_workers=4) as ex:
    futs = [ex.submit(fetch, i) for i in range(5)]
    print(sorted(f.result() for f in as_completed(futs)))
```

### 2.2 对照写法

```python
import threading, queue
q = queue.Queue()
def worker():
    while True:
        item = q.get()
        if item is None: break
        q.task_done()
t = threading.Thread(target=worker, daemon=True); t.start()
q.put(1); q.join(); q.put(None)
```
