# 关于本站

这是一套面向零基础学习者、一路走到资深能力的交互式 Python 中文教程：**13 个递进阶段、132 讲、50 个工程场景**。

## 编排思路

阶段顺序按依赖关系倒推，而不是按知识点罗列：先能对（语法与对象模型），再能快（核心机制与并发），再能发布（工程化与服务端），最后能担责（分布式、架构与源码）。每讲固定按「建立直觉 → 跑通示例 → 深入边界 → 工程实践 → 动手练习 → 随堂检测 → 一页纸速记」推进，保证主动回忆的次数远多于被动阅读。

<Callout type="idea" title="为什么这样设计" text="语言教学的难点不是信息不足，而是缺少可验证的反馈。本站把每段结论都绑到一段可运行代码、一次输出猜测或一道即时反馈的题目上，让「以为懂了」在页面内就能被检验。" />

## 站点能力

| 能力 | 说明 |
| --- | --- |
| 交互组件 | 27 个 Vue 组件，24 个全局注册，覆盖问答、填空、预测、逐行讲解、概念图、时序图与分层蓝图 |
| 代码块增强 | 语言标签、一键复制、整块折叠、按结构行内折叠、在线运行入口（Python 代码块） |
| 表格增强 | 短列不换行、宽表横向滚动、首列固定、滚动渐隐提示 |
| 概念图 | 每讲一张专属可放大图，支持滚轮 / 双指缩放、拖拽平移与 ESC 关闭 |
| 学习进度 | 逐页打卡、按阶段汇总、一键清空，数据只存浏览器本地 |
| 阅读体验 | 浅色 / 深色双主题、本地全文搜索、目录大纲、上一节 / 下一节 |
| 发布 | 推送 main 由 GitHub Actions 自动构建并发布到 GitHub Pages |
