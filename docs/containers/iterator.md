**__iter__ 与 __next__**。这里的关键词是「什么时候」和「代价是什么」。Python 的机制大多不是非黑即白的开关，而是在可读性、性能与灵活性之间做的取舍。把取舍写清楚，遇到新版本或新框架时才能自己推导，而不是重新背一遍结论。

```python
def pipeline(lines):
    cleaned = (l.strip() for l in lines)
    return (l for l in cleaned if l and not l.startswith("#"))

lines = iter([" a ", "# note", "", " b "])
print(list(pipeline(lines)))
```
