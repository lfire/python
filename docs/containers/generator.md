# 第 026 讲 · 生成器与 yield：send / throw / close

> yield 把函数变成可暂停的状态机：局部变量、指令指针都留在帧里，恢复时从上次位置继续，这正是后来 async/await 的基座。本讲的目标是「掌握协程的雏形与状态机写法」。先建立直觉，再用可运行代码把规则固定下来，最后放进工程场景里看边界与代价；全程建议边读边改参数、边猜输出。

## 2. 语法与规则：把行为跑出来

### 2.1 主示例

**生成器函数与 yield**。从实现角度看，这一层的行为最终会落到对象协议、字节码或运行时状态上。理解底层并不意味着每次都要写底层代码，而是当现象与直觉不符时，你知道该用 dis、inspect、tracemalloc 还是 cProfile 去验证，从而把猜测变成证据。

```python
def counter(n):
    for i in range(n):
        yield i * i

g = counter(4)
print(next(g), next(g))
print(list(g))
```
