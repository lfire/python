## 4. 工程实践

用 NamedTuple 或 dataclass(frozen=True) 给字段命名，既保留不可变性又让接口自解释 **与 list 的取舍**。建议把它和相邻知识点连成一条线：输入是什么、状态存在哪里、失败时谁负责收尾。这三问能覆盖绝大多数线上问题，也是后续阶段反复使用的分析框架；能回答这三问，才算真正掌握而不是记住了 API 名字。 落地时把这条结论写进检查表或自动化测试，避免只停留在口头约定。
