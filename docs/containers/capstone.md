## 2. 语法与规则：把行为跑出来

### 2.1 主示例

**文本规整与分词**。工程里最容易出问题的不是不会用，而是用在错误的边界上：数据规模变大、并发进入、依赖升级、跨平台部署之后，原本成立的假设会逐个失效。因此本讲同时给出适用条件、失效信号和一条可回退的路径。

```python
from collections import Counter

def top_words(lines, n=3):
    c = Counter()
    for line in lines:
        c.update(w.lower() for w in line.split() if w.isalpha())
    return c.most_common(n)

print(top_words(["A a b", "b c A"]))
```

### 2.2 对照写法

```python
class KV:
    def __init__(self):
        self._d = {}
    def set(self, k, v): self._d[k] = v
    def get(self, k): return self._d.get(k)

kv = KV(); kv.set("x", 1)
print(kv.get("x"))
```
