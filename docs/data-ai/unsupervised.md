### 2.1 主示例

**聚类假设与尺度**。从实现角度看，这一层的行为最终会落到对象协议、字节码或运行时状态上。理解底层并不意味着每次都要写底层代码，而是当现象与直觉不符时，你知道该用 dis、inspect、tracemalloc 还是 cProfile 去验证，从而把猜测变成证据。

```python
# 决策边界直觉：最近邻分类
from collections import Counter
train = [(1, "A"), (2, "A"), (8, "B")]
def knn(x, k=2):
    near = sorted(train, key=lambda t: abs(t[0]-x))[:k]
    return Counter(label for _, label in near).most_common(1)[0][0]
print(knn(3), knn(7))
```
