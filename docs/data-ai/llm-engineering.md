# 第 104 讲 · LLM 应用工程：Prompt、RAG、Agent 与成本

> 大模型应用的工程质量主要在模型之外：检索质量、上下文预算、工具幂等、失败降级与可观测性，而不是提示词措辞。本讲的目标是「把大模型能力做成可靠、可控、可观测的应用」。先建立直觉，再用可运行代码把规则固定下来，最后放进工程场景里看边界与代价；全程建议边读边改参数、边猜输出。
