## 一份含极端大值的收入报表，均值骗了谁

A/B 实验上线前，分析师拿一份转化数据算均值，发现比历史高 30%，主张立刻全量。复核时发现样本里混进一笔测试环境的 100 万元极值，均值被单条记录拉飞，中位数却几乎没动；换用正确的描述统计后提升只剩 3%。

更要命的是另一份报告：团队每天检验一次，连查二十天终于出现 p 小于 0.05，就宣布策略有效——反复检验直到显著，等于把偶然当成规律。还有人把「冰淇淋销量与溺水数高度相关」写成因果结论，忽略了两者都被气温驱动。这些错误的共同点是把统计当成「套公式算一个数」，却没问数据怎么来的、均值是否稳健、p 值在什么前提下才有意义。

本讲把建模前的判断落到能实跑核对的标准库统计上。

## 描述统计：均值、中位数与 1.5 倍 IQR 离群点

statistics 模块提供 mean、fmean、median、median_low/high、mode/multimode、pstdev、stdev、variance、quantiles。mean 是算术平均，对极值极其敏感；

median 是排序后的中间值，抗离群点，因而在偏态分布（收入、订单金额、停留时长）里更能代表典型水平。stdev 除以 n-1（样本标准差，用贝塞尔校正做无偏估计），pstdev 除以 n（总体标准差），两者在 n 小时差得明显，混淆会低估或高估离散度；注意它们要求至少两个数据点，pstdev 一个点返回 0。

quantiles(data, `n=4`, method='exclusive') 默认用 exclusive 方法返回 3 个四分位点，可改 method='inclusive' 得到另一种定义；基于 Q1、Q3 的 `IQR = Q3` - Q1，常用 1.5 倍 IQR 之外判离群点，这正是箱线图须线的规则。

判断该用均值还是中位数，先看分布形状：对称且无极值用均值配标准差，偏态或有厚尾用中位数配 IQR。数据怎么来的比算法更重要：抽样偏差、缺失机制、幸存者偏差往往比选哪个模型影响更大，例如只统计「还活跃的用户」会系统性高估留存。

```python
import statistics as st
data = [12, 15, 14, 16, 15, 100, 13, 14, 15, 14]
print('mean', st.mean(data))
print('median', st.median(data))
print('stdev', round(st.stdev(data), 3))
print('pstdev', round(st.pstdev(data), 3))
q = st.quantiles(data, n=4)
print('q1 q2 q3', q)
iqr = q[2] - q[0]
lo, hi = q[0] - 1.5 * iqr, q[2] + 1.5 * iqr
print('fences', round(lo, 1), round(hi, 1))
print('outliers', [x for x in data if x < lo or x > hi])
```

## 抽样、中心极限定理与置信区间：从直觉到公式

中心极限定理说的是：只要总体方差有限，从任意分布里独立抽取容量为 n 的样本，样本均值的分布会随着 n 增大逼近正态，均值约等于总体均值，标准差（标准误）约等于总体标准差除以 n 的平方根。这与总体本身是否正态无关——哪怕总体是均匀分布，`n=30` 的样本均值也近似钟形。

标准误随根号 n 衰减，意味着把精度提高一倍要四倍样本，这是估算样本量的直接依据。置信区间把这种不确定性写成区间：95% 置信区间约为 均值 ± 1.96 乘标准误（大样本、已知或估计标准差的近似），含义是「在重复抽样下，这样构造的区间有 95% 会覆盖真值」，而不是「真值有 95% 概率落在这个具体区间里」——后者是常见误读。

样本小时应改用 t 分布临界值而非 1.96。

用 `random.seed` 固定种子、`random.choices` 做有放回抽样、`statistics.mean`/stdev 复算，能在纯标准库里把这条定理变成可复现的数值证据：把总体设成 1 到 100 的均匀分布，抽 2000 组每组 30 个，样本均值的均值应贴近 50.5、标准差贴近总体标准差除以根号 30。

## 假设检验与 p 值：最小实现与数值验证

假设检验先立原假设 H0（如「两组均值无差异」）与显著性水平 alpha（常取 0.05），再算检验统计量并得到 p 值：在 H0 成立的前提下，观察到当前或更极端数据的概率。p 小于 alpha 只说明「数据与 H0 不太相容」，不等于「效应很大」「结论为真」或「有 95% 概率正确」。

两类错误要分清：第一类错误是 H0 为真却拒绝（概率由 alpha 控制），第二类错误是 H0 为假却没拒绝（与功效、样本量有关）。

反复检验直到 p 显著会累积第一类错误：独立做 20 次 `alpha=0.05` 的检验，至少一次假阳性的概率约 1 - 0.95 的 20 次方，接近 0.64，因此多重比较要做 Bonferroni 之类校正或预先注册假设与样本量。

相关系数（Pearson r）只度量线性共变，值域 -1 到 1，两个变量都由第三个混杂变量驱动时 r 可以很高却毫无因果关系；冰淇淋销量与溺水数都随气温上升就是典型。要谈因果需要随机对照实验、控制混杂或因果推断设计，而不是看 r 的大小。业务结论必须标注适用边界与数据来源，不能把探索性相关写成决策依据。

```python
import random, statistics as st
random.seed(7)
pop = list(range(1, 101))
means = [st.mean(random.choices(pop, k=30)) for _ in range(2000)]
print('population mean', st.mean(pop))
print('population pstdev', round(st.pstdev(pop), 3))
print('means mean', round(st.mean(means), 3))
print('means stdev', round(st.stdev(means), 3))
print('predicted SE', round(st.pstdev(pop) / (30 ** 0.5), 3))
```

<OutputBox title='对照写法：先自己猜，再点开' output='population mean 50.5\npopulation pstdev 28.866\nmeans mean 50.399\nmeans stdev 5.358\npredicted SE 5.27' guess="true" />

```python
def pearson(x, y):
    n = len(x)
    mx, my = sum(x) / n, sum(y) / n
    num = sum((a - mx) * (b - my) for a, b in zip(x, y))
    dx = sum((a - mx) ** 2 for a in x) ** 0.5
    dy = sum((b - my) ** 2 for b in y) ** 0.5
    return round(num / (dx * dy), 4)

t = list(range(1, 11))
ice = [20 + 3 * i for i in t]
drown = [5 + 2 * i for i in t]
print('r(ice, drown)', pearson(ice, drown))
print('alpha .05 x20 false-positive', round(1 - 0.95 ** 20, 3))
```

## 相关不等于因果、多重比较与效应量的边界

均值的最小二乘性质决定了它对离群点敏感：最小化 `sum((x - c)`^2) 的解正是算术平均，单个极端值会以平方项主导目标函数；中位数最小化 `sum(|x - c|)`，是 L1 意义下的稳健中心。

样本方差除以 n-1 来自贝塞尔校正：用样本均值替代未知总体均值会损失一个自由度，除以 n 会系统性低估，除以 n-1 才无偏。

中心极限定理可由特征函数或矩母函数证明：独立同分布变量之和的标准化特征函数收敛到 `exp(-t^2/2)`，即标准正态的特征函数，因而样本均值分布逼近正态，标准误为 sigma/根号 n，收敛速度依赖总体偏度。Pearson r 定义为协方差除以两标准差之积，本质是两个中心化向量的夹角余弦，只捕捉线性共变；

当 x 与 y 都是第三个变量 z 的线性函数时二者夹角为零、`r=1`，但 x 并不导致 y。p 值是在 H0 下尾概率的积分，多重检验把每次 alpha 的假阳性以 1-(1-alpha)^m 累积，这就是「反复检验直到显著」失效的数学根源。

**均值 vs 中位数的稳健性（本章样本）**

| 统计量 | 含 100 的结果 | 去掉 100 后 | 结论 |
| --- | --- | --- | --- |
| mean | 22.8 | 14.22 | 被单条极值大幅拉高 |
| median | 14.5 | 14 | 几乎不受影响 |
| stdev | 27.149 | 1.2 | 离散度被极值放大 |

**p 值与相关的常见误读**

| 说法 | 是否成立 | 正确理解 |
| --- | --- | --- |
| p<0.05 说明效应很大 | 否 | p 只衡量与 H0 的相容性，效应量另算 |
| p<0.05 说明结论 95% 为真 | 否 | 是关于重复抽样下区间/检验频率的陈述 |
| 连查 20 次总会显著仍算证据 | 否 | 假阳性概率升到约 0.64，需多重校正 |
| r 接近 1 说明有因果 | 否 | 可能由共同混杂变量驱动 |

**错因速查**

| 现象 | 根因 | 正确写法 |
| --- | --- | --- |
| 用均值描述收入、订单额等偏态数据 | 均值最小化平方误差，单条极值会以平方项拉高结果 | 改看中位数与 IQR，或先按 1.5 倍 IQR 规则识别并说明离群点处理方式 |

## 上线前的探索性分析：先判断数据能不能信

一个灰度实验要比较新策略的订单金额，直接算均值差很容易被极值、抽样偏差和幸存者偏差带偏。稳妥流程是：先做描述统计（均值、中位数、标准差、分位数、IQR 围栏识别离群点），判断分布是否偏态；再估计标准误与 95% 置信区间，看效应是否大于噪声；最后才考虑检验，并预先定好 alpha 与样本量。

下面用标准库把前三步固化成一个可复跑的函数：它同时输出均值与中位数、围栏外的样本数、标准误与区间，让「该不该继续」有可核对的数字，而不是一个孤零零的均值。真实项目把 sample 换成数据库查询结果，结论里仍需写明数据来源与适用窗口。

```python
import statistics as st

def explore(sample):
    q = st.quantiles(sample, n=4)
    iqr = q[2] - q[0]
    lo, hi = q[0] - 1.5 * iqr, q[2] + 1.5 * iqr
    outliers = [x for x in sample if x < lo or x > hi]
    se = st.stdev(sample) / (len(sample) ** 0.5)
    mean = st.mean(sample)
    return {
        'n': len(sample),
        'mean': round(mean, 2),
        'median': st.median(sample),
        'stdev': round(st.stdev(sample), 2),
        'outliers': len(outliers),
        'se': round(se, 2),
        'ci95': [round(mean - 1.96 * se, 2), round(mean + 1.96 * se, 2)],
    }

sample = [12, 15, 14, 16, 15, 13, 14, 15, 14, 16, 13, 15, 100]
print(explore(sample))
```

**速记索引**

| 要记住的结论 | 用在哪一步 |
| --- | --- |
| 均值最小化平方误差、怕极值；中位数最小化绝对误差、抗离群点；偏态数据用中位数配 IQR | 建立直觉 |
| stdev 除以 n-1（样本、无偏），pstdev 除以 n（总体）；quantiles 默认 exclusive 方法 | 跑通示例 |
| 1.5 倍 IQR 之外判离群点，是箱线图须线规则 | 深入边界 |
| 中心极限定理：样本均值逼近正态，标准误 = sigma/根号 n，精度翻倍需四倍样本 | 工程落地 |
| 95% 置信区间约 均值 ± 1.96·SE，是重复抽样覆盖率，不是「真值概率」 | 随堂检测 |
| p 值是 H0 下尾概率；反复检验累积假阳性（20 次约 0.64）；相关高不等于因果 | 复盘 |
