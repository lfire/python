# 阶段导览 · 数据与 AI

服务会产生数据，而数据只有被整理、被检验、被画出来，才谈得上支撑判断。这一阶段从最朴素的数据操作起步，一路走到把模型能力做成可用的产品。

先把 NumPy 的向量化、Pandas 的清洗与分组、可视化和统计基础铺好，再进入机器学习流程、经典算法、SVM 与树模型、集成学习、无监督方法、模型调优，然后是深度学习与 PyTorch，最后收在 LLM 应用工程。递进是「把数据摆整齐 → 建立可解释的基线 → 用统一指标评估 → 在工程上把不确定性关进笼子」。第九十七讲的数据泄漏和第一百零二讲的过拟合会反复出现，因为绝大多数模型分数虚高都源自这两处。

不需要很深的数学基础，但每步都要能说清假设与适用边界。涉及第三方库的讲次，主示例刻意用标准库或纯 Python 模拟核心机制，保证你先把原理跑通，再决定装哪个库。第一〇四讲的 RAG 与 Agent 则会把视角从模型拉回到检索质量、预算与降级这些工程问题上。
