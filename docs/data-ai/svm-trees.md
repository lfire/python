### 2.1 主示例

**间隔最大化与核技巧**。先把这个概念放进可验证的场景：写一段最小代码，观察它的输出，再回头读规则。很多误解来自只记结论、没有亲手跑过边界情况；本讲要求把每一步的结论都用一段可运行代码固定下来，而不是停在「大概是这样」。

```python
# 决策边界直觉：最近邻分类
from collections import Counter
train = [(1, "A"), (2, "A"), (8, "B")]
def knn(x, k=2):
    near = sorted(train, key=lambda t: abs(t[0]-x))[:k]
    return Counter(label for _, label in near).most_common(1)[0][0]
print(knn(3), knn(7))
```
