# 阶段导览 · 分布式云原生

> 从单机思维升级到分布式与云原生思维，能担责稳定性。本阶段共 9 讲，覆盖 一致性、幂等、分布式事务、分片、容器与 K8s、调度、SRE、安全。建议按顺序推进：每讲都先建立直觉、再跑通示例、最后看工程边界，讲与讲之间的依赖关系在下面的地图里一目了然。

## 这个阶段解决什么问题

一致性、幂等、分布式事务、分片、容器与 K8s、调度、SRE、安全。阶段划分不是按知识点罗列，而是按「学完能交付什么」倒推：前一阶段的输出正好是这一阶段的前置，跳过某一段往往会在后面某讲突然卡住，届时再回来补齐比按顺序学更费时。
