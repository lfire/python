## 2. 语法与规则：把行为跑出来

### 2.1 主示例

**本地事务边界**。工程里最容易出问题的不是不会用，而是用在错误的边界上：数据规模变大、并发进入、依赖升级、跨平台部署之后，原本成立的假设会逐个失效。因此本讲同时给出适用条件、失效信号和一条可回退的路径。

```python
# 令牌桶限流
import time
class Bucket:
    def __init__(self, rate, cap):
        self.rate, self.cap, self.tokens, self.t = rate, cap, cap, time.monotonic()
    def allow(self):
        now = time.monotonic()
        self.tokens = min(self.cap, self.tokens + (now - self.t) * self.rate)
        self.t = now
        if self.tokens < 1: return False
        self.tokens -= 1
        return True
b = Bucket(1, 2)
print(b.allow(), b.allow(), b.allow())
```
