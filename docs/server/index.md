# 阶段导览 · 服务端与数据

包能发布了，下一步是让它对外提供服务。一个请求从进来到返回，中间要经过协议解析、校验、业务编排、数据落库、缓存、异步任务与鉴权——这一阶段就是把这条链路逐段拆开。

内容从 HTTP 与 WSGI/ASGI 的差别开始，经过框架选型、路由与依赖注入、REST 与幂等、实时推送、ORM 与事务、Redis 缓存、消息队列、认证授权、对象存储与 gRPC，最后由生产级短链服务收束。递进顺序按一次请求的生命周期走：先看清它怎么进来，再看数据怎么存、怎么加速，最后看失败时怎么降级。第八十七讲的 N+1 查询和第八十八讲的缓存击穿，都是只有数据量上来才会显形的问题，建议配合压测一起读。

需要你已经熟悉函数、异常、模块与基本的 SQL。框架部分不站队：我们更关心每个方案替你决定了多少，以及当它不再合适时替换成本有多大。
