### 2.1 主示例

**发号与 Base62**。工程里最容易出问题的不是不会用，而是用在错误的边界上：数据规模变大、并发进入、依赖升级、跨平台部署之后，原本成立的假设会逐个失效。因此本讲同时给出适用条件、失效信号和一条可回退的路径。

```python
# FastAPI 风格（示意，需 pip install fastapi uvicorn）
from typing import Optional
from pydantic import BaseModel, Field

class ItemIn(BaseModel):
    name: str = Field(min_length=1)
    price: float = Field(gt=0)

def create(item: ItemIn, idem: Optional[str] = None):
    return {"name": item.name, "price": item.price, "idem": idem}

print(create(ItemIn(name="book", price=29.9), "k-1"))
```
