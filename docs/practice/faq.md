# 零基础常见问题

<Callout type="tip" title="提问之前" text="先记录 Python 版本、依赖版本、最小复现输入与完整报错栈；这四项能解决大半问题，也是有效提问的最低信息量。" />

### 该学 Python 2 还是 3？

只学 Python 3。Python 2 已于 2020 年停止维护，字符串模型与 print 语法的差异会让旧教程的结论失效；本站全部示例基于 3.10+。

### 虚拟环境到底解决什么问题？

隔离解释器与依赖集合。不同项目对同一库的版本要求常冲突，全局安装会让它们互相污染，也无法复现生产环境。

### 为什么 0.1 + 0.2 不等于 0.3？

二进制浮点无法精确表示 0.1。用 math.isclose 做近似比较，金额计算改用 Decimal 并明确量化规则。

### GIL 是不是意味着 Python 不能并发？

不是。IO 密集场景可用线程池或 asyncio 获得高并发，CPU 密集才需要多进程、原生扩展或向量化。

### list 和 tuple 怎么选？

需要原地增删用 list；表达固定结构、作为字典键或函数多返回值用 tuple，字段多时改用 NamedTuple 或 dataclass。

### 深拷贝能解决所有共享问题吗？

不能。深拷贝成本高且无法复制外部资源（连接、文件句柄）；更好的做法是在接口边界明确所有权与只读视图。

### 装饰器为什么要写 functools.wraps？

不写会让所有被装饰函数的 __name__、__doc__、签名都变成 wrapper，日志、文档生成、依赖注入与调试都会失真。

### async 函数里能直接调 requests 吗？

不能。同步阻塞调用会占住整个事件循环，应使用原生异步库，或把阻塞调用放进 to_thread / run_in_executor。

### pytest 的 fixture 和 mock 该用哪个？

fixture 负责准备状态，mock 负责替换不可控依赖；优先用假实现（fake）与依赖注入，少做调用次数的深度断言。

### 类型注解会在运行时校验吗？

不会。注解默认只是元数据，约束力来自 mypy / pyright；运行时校验要用 pydantic 之类的模型层。

### 为什么本地能导入、打包后就 ModuleNotFoundError？

通常是扁平布局下误用隐式相对导入，或把测试与包混放。改用 src 布局并以安装后的包来跑测试。

### 装饰器叠加顺序怎么记？

离函数最近的先包装，最上面的先执行。顺序错了可能让缓存包住鉴权，把未授权结果也缓存下来。

### 生成器为什么只能遍历一次？

迭代器自带状态且不保存全部元素。需要反复遍历就用容器，或用 itertools.tee 显式复制。

### SQL 拼接有什么风险？

字符串拼接会把输入变成可执行 SQL，形成注入。始终用参数化查询，并把动态标识符做白名单校验。

### 缓存穿透、击穿、雪崩分别是什么？

穿透是查不存在的数据，击穿是热点键失效瞬间大量重建，雪崩是大批键同时过期；对应空值缓存、互斥重建、TTL 抖动。

### JWT 真的无状态到不需要服务端存储吗？

签发后无法主动失效，实际系统仍需要短时效、刷新令牌、黑名单或版本化密钥来保留撤销能力。

### 机器学习里验证集和测试集有什么区别？

验证集用于选模型与调参，测试集只在最终评估用一次。在测试集上反复调参等于把它变成验证集。

### Docker 镜像太大怎么瘦？

多阶段构建把编译依赖留在 builder 层，运行层只装锁文件里的运行依赖，并选 slim 基础镜像、非 root 运行。

### 什么时候不该拆微服务？

领域边界不清、团队规模小、发布节奏一致时。先把模块化单体的边界与契约测试做好，再按真实痛点拆。

### 学完这套教程能达到什么水平？

能独立设计并交付生产级 Python 服务、数据管道或 AI 应用，能读 CPython 源码解释现象，也能对架构与性能做出带代价评估的技术决策。
