## 高频考点索引

- **导学**：Python 的诞生与设计哲学、CPython 与 PyPy 等实现、脚本与交互式解释器
- **编程地基**：对象的三要素、赋值即绑定、int 的任意精度实现
- **容器与序列**：序列与可迭代的区别、列表的连续存储、切片赋值与步长
- **函数与抽象**：位置与关键字参数、隐式 return None、LEGB 查找顺序
- **面向对象**：类对象与实例对象、__mro__ 与 C3 线性化、名称改写与私有约定
- **核心机制**：词法与语法分析、栈式指令与 LOAD / STORE、帧对象与 f_locals / f_globals
- **并发与异步**：并发与并行的区别、Thread 与 daemon、Lock 与 RLock
- **工程化**：src 与扁平布局对比、pyproject.toml 规范、PEP 8 的取舍
- **服务端与数据**：请求响应模型、三者定位差异、路径与查询参数
- **数据与 AI**：ndarray 与 dtype、Series 与 DataFrame 索引、图表类型与数据关系
- **分布式云原生**：CAP 的正确表述、幂等键设计、本地事务边界
- **资深进阶**：源码目录结构、arena / pool / block 三级、importlib._bootstrap
- **工程实战**：命令解析 argparse / click、pathlib 遍历与 glob、smtplib / yagmail 与授权码
