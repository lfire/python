# Python 生态与选型地图

## 12 类工程领域

| 领域 | 场景数 | 代表项目 |
| --- | --- | --- |
| 命令行与工具链 | 3 个场景 | 待办清单 CLI、批量重命名与文件整理器、代码生成器与模板引擎 |
| 办公自动化 | 5 个场景 | 文件检索与容量统计、邮件 / PDF 批处理、Excel / Word 报表流水线、图片与视频批处理、Selenium  |
| 网络服务 | 4 个场景 | 生产级短链服务、图片服务与对象存储、实时推送与 WebSocket、RESTful 开放平台 API |
| 数据采集与爬虫 | 4 个场景 | 静态页面图片批量下载、Scrapy 多站点采集、登录态与异步接口采集、反爬对抗与合规策略 |
| 数据处理与分析 | 4 个场景 | 疫情 / 房价数据分析、日志 ETL 管道、CSV / SQL 查询工具、医院科室费用透视 |
| 存储与中间件 | 5 个场景 | KV ① 内存版、KV ② 网络协议帧、KV ③ WAL 与恢复、KV ④ 分片与副本、Redis 缓存与分布式锁 |
| 微服务架构 | 4 个场景 | 自研 RPC 框架、电商订单服务、API 网关与熔断、秒杀与高并发库存 |
| 云原生与 SRE | 5 个场景 | Docker 多阶段构建、Kubernetes 部署与 HPA、GitOps 灰度发布、全链路可观测平台、分布式任务调度 |
| 测试与质量 | 3 个场景 | 接口自动化测试框架、Web UI 自动化测试、属性测试与基准回归 |
| 数据与 AI 工程 | 7 个场景 | 经典算法建模与调参、图像分类与迁移学习、漫画脸风格生成、医学影像端到端判别、RAG 财报问答系统、智能选题 / PPT  |
| 安全与治理 | 3 个场景 | 依赖漏洞与 SBOM 审计、认证授权与审计日志、配置与密钥托管 |
| 跨语言与底层 | 3 个场景 | ctypes / cffi 调用 C 库、Cython 热点加速、WASM 与插件沙箱 |

## 选型维度

| 维度 | 要问的问题 |
| --- | --- |
| 维护状态 | 最近发版时间、issue 响应、是否支持当前 Python 版本 |
| 依赖面 | 传递依赖数量、是否引入编译工具链、是否有 C 扩展 |
| 性能特征 | 是否有 GIL 释放、内存占用、冷启动开销 |
| 可观测性 | 日志结构化、指标暴露、追踪注入是否方便 |
| 退出成本 | API 是否可被一层适配器隔离，替换时要改多少处 |
| 许可与合规 | 许可证、供应链扫描、镜像与 SBOM |
