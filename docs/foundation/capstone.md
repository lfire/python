## 2. 语法与规则：把行为跑出来

### 2.1 主示例

**需求拆解与输入循环**。从实现角度看，这一层的行为最终会落到对象协议、字节码或运行时状态上。理解底层并不意味着每次都要写底层代码，而是当现象与直觉不符时，你知道该用 dis、inspect、tracemalloc 还是 cProfile 去验证，从而把猜测变成证据。

```python
import operator
OPS = {"+": operator.add, "-": operator.sub,
       "*": operator.mul, "/": operator.truediv}

def calc(expr):
    a, op, b = expr.split()
    return OPS[op](float(a), float(b))

print(calc("6 / 2"))
```

### 2.2 对照写法

```python
def safe_calc(expr):
    try:
        return calc(expr)
    except (ValueError, KeyError, ZeroDivisionError) as e:
        return f"错误：{type(e).__name__}"

print(safe_calc("1 / 0"))
```
