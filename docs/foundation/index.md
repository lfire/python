# 阶段导览 · 编程地基

环境能跑起来之后，我们开始处理最基础也最容易含糊的一层：一个值到底是什么，名字和值是什么关系，以及程序如何表达「如果」和「重复」。这些问题的答案会一路影响到后面的容器、闭包、描述符和并发，所以值得慢一点。

这个阶段从 id、type、value 三个角度切开对象模型，再到变量绑定、数值精度、字符串与编码、运算符、分支、循环、文件读写和异常，最后用一个交互式命令行计算器把这些零件装在一起。递进顺序是「先认清对象 → 再会操作单个值 → 再会控制流程 → 最后能处理出错」。其中数值精度和字符串编码两讲，最容易在真实项目里变成线上事故，建议把示例代码亲手改坏一次。

常见误区是急着背语法而跳过对象模型，等到遇见「改了一个列表，另一个名字也变了」时再回头补，代价反而更大。每讲结尾都有一页纸速记，读完可以先用它自测，不必追求一次记全。
