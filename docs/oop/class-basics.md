# 第 038 讲 · 类与实例：__init__、self 与属性

> 真正创建实例的是 __new__，__init__ 只负责初始化；方法之所以能自动收到 self，是因为函数实现了描述符协议。本讲的目标是「建立对象创建与属性存储的准确模型」。先建立直觉，再用可运行代码把规则固定下来，最后放进工程场景里看边界与代价；全程建议边读边改参数、边猜输出。

## 1. 先建立直觉

**类对象与实例对象**。工程里最容易出问题的不是不会用，而是用在错误的边界上：数据规模变大、并发进入、依赖升级、跨平台部署之后，原本成立的假设会逐个失效。因此本讲同时给出适用条件、失效信号和一条可回退的路径。

**__init__ 不是构造函数**。建议把它和相邻知识点连成一条线：输入是什么、状态存在哪里、失败时谁负责收尾。这三问能覆盖绝大多数线上问题，也是后续阶段反复使用的分析框架；能回答这三问，才算真正掌握而不是记住了 API 名字。

## 2. 语法与规则：把行为跑出来

### 2.1 主示例

**类对象与实例对象**。建议把它和相邻知识点连成一条线：输入是什么、状态存在哪里、失败时谁负责收尾。这三问能覆盖绝大多数线上问题，也是后续阶段反复使用的分析框架；能回答这三问，才算真正掌握而不是记住了 API 名字。

```python
class User:
    kind = "member"          # 类属性
    def __init__(self, name):
        self.name = name     # 实例属性

u = User("Ada")
print(u.kind, User.kind, u.__dict__)
```
