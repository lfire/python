# 阶段导览 · 面向对象

> 从会写类到能设计对象协议、描述符与元类驱动的框架。本阶段共 11 讲，覆盖 类与实例、MRO、描述符、特殊方法、ABC、元类、dataclass 与 ORM 雏形。建议按顺序推进：每讲都先建立直觉、再跑通示例、最后看工程边界，讲与讲之间的依赖关系在下面的地图里一目了然。

## 这个阶段解决什么问题

类与实例、MRO、描述符、特殊方法、ABC、元类、dataclass 与 ORM 雏形。阶段划分不是按知识点罗列，而是按「学完能交付什么」倒推：前一阶段的输出正好是这一阶段的前置，跳过某一段往往会在后面某讲突然卡住，届时再回来补齐比按顺序学更费时。
